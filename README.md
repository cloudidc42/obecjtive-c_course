# หลักสูตร Objective-C ระดับมืออาชีพและระดับโลก

## ภาษา Objective-C คืออะไร?

Objective-C เป็นภาษาโปรแกรมคอมพิวเตอร์เชิงวัตถุ (Object-Oriented Programming) ระดับสูง ที่พัฒนาต่อยอดมาจากภาษา C โดยเพิ่มระบบการส่งข้อความแบบ Smalltalk พัฒนาขึ้นโดย Brad Cox และ Tom Love ในปี ค.ศ. 1984 และต่อมาถูก Apple นำมาใช้เป็นภาษาหลักสำหรับการพัฒนา macOS และ iOS จนกระทั่ง Swift เปิดตัวในปี 2014

## ทำไมต้องเรียน Objective-C ในปี 2024+?

- **Legacy Code**: มี codebase ขนาดใหญ่ของ iOS/macOS ที่เขียนด้วย Objective-C
- **Foundation ของ Swift**: เข้าใจ Swift ได้ลึกขึ้นเมื่อรู้ Objective-C
- **Framework Integration**: หลาย Apple frameworks เขียนด้วย Objective-C
- **Interoperability**: Objective-C และ Swift ทำงานร่วมกันได้
- **Performance**: เข้าใจ runtime behavior ได้ลึกขึ้น
